Model kasar casing node sensor IoT (ESP32 + DHT22) dengan logo di penutup atas. Seret model untuk memutar; panel di sebelahnya mengatur sudut pandang, mode kerangka, bongkar casing, zoom, dan warna.

Alur data

  1. SensorTMP36 ×2, potensiometer ×2
  2. Arduino Unobaca & kirim lewat Serial
  3. Serial Monitorteks 1 baris tiap detik
  4. FermentoSensetempel / USB Serial / simulator
  5. Dashboardcek batas, grafik, notifikasi

Tinkercad berjalan di cloud dan tidak punya jalur keluar ke website lain, sehingga data dari Serial Monitor Tinkercad dipindahkan dengan fitur Tempel Serial Monitor (klik “Sumber Data” di kanan atas). Untuk Arduino/ESP32 asli yang tersambung USB, gunakan tab USB Serial (Chrome/Edge) agar data masuk otomatis.

Pengganti komponen di Tinkercad

Komponen prototype asliPengganti di TinkercadPinDibaca sebagai
ESP32Arduino Uno–Mikrokontroler
DS18B20TMP36 pertamaA0T – suhu media (°C)
DHT22 (suhu)TMP36 keduaA1A – suhu udara (°C)
DHT22 (kelembapan)Potensiometer pertamaA2H – kelembapan (0–100 %)
Sensor pHPotensiometer keduaA3PH – pH (0–14)
BuzzerPiezo buzzerD8Bunyi jika suhu media > batas

Kabel TMP36: kaki kiri → 5V, tengah → pin analog, kanan → GND. Potensiometer: ujung → 5V & GND, wiper (tengah) → pin analog. Piezo: + → D8, – → GND.

Aturan pengolahan data & notifikasi

ParameterKondisiAksi
Suhu media> 38 °CBuzzer berbunyi + notifikasi “suhu terlalu tinggi”
Suhu ruangan> 38 °CBuzzer berbunyi + notifikasi “suhu ruangan terlalu tinggi”
Kelembapan udara< 70 % atau > 90 % RHNotifikasi “kelembapan tidak sesuai”
pH> 7,5Notifikasi “kemungkinan fermentasi berlebihan”
Semua parameter dalam batas–Dashboard menampilkan status Normal

Notifikasi dikirim saat kondisi berubah (normal → melewati batas, dan sebaliknya), jadi tidak membanjiri daftar tiap detik. Batas dapat diubah di menu Pengaturan.

Format data yang dipahami

        
Satu baris per pembacaan. Semua format berikut diterima:

        
T=31.2;A=29.0;H=74.0;PH=5.70
suhu=31.2, kelembapan=74, ph=5.7
{"temp":31.2,"air":29.0,"hum":74,"ph":5.7}
31.2,74,5.7            (suhu, kelembapan, pH)
31.2,29.0,74,5.7       (suhu media, suhu udara, kelembapan, pH)

Format sketch Tinkercad tim (Arduino Uno), satu blok per siklus:
===== HASIL MONITORING =====
Suhu Media  : 31.20 C
Suhu Udara  : 29.00 C
Kelembapan  : 74.00 % RH
pH          : 5.70
STATUS: NORMAL
→ blok diproses saat baris pH tiba; baris ALARM/STATUS diabaikan (dashboard menghitung sendiri).

Format sketch Wokwi tim (ESP32, 3×DS18B20 + DHT22), beberapa baris per siklus:
DS18B20 Sensor 1: 27.31 ºC
DS18B20 Sensor 2: 27.25 ºC
DS18B20 Sensor 3: 27.38 ºC
DHT22 Humidity: 50.5 %	DHT22 Temperature: 23.1 ºC
→ suhu media = rata-rata 3 DS18B20, suhu udara & kelembapan = DHT22.
  (pH belum ada di sketch Wokwi tersebut, jadi kartu pH menunggu data.)

Pemisah kolom boleh koma, titik koma, atau tab. Kolom lain (mis. status) diabaikan. Jika ada kolom waktu, data dianggap historis: grafik dan riwayat mengikuti waktunya, dan waktu mulai batch disesuaikan bila data lebih awal.

        
import pandas as pd
import numpy as np

# contoh: 24 jam data, satu baris tiap 15 menit
n = 24 * 4
i = np.arange(n)
df = pd.DataFrame({
    "waktu": pd.date_range("2025-01-20 08:00", periods=n, freq="15min"),
    "suhu_media_C": np.round(27 + 6 * (1 - np.exp(-i / 16)), 2),
    "suhu_ruangan_C": np.round(26 + np.random.rand(n), 2),
    "kelembapan_persen": np.round(65 + 12 * (1 - np.exp(-i / 12)), 1),
    "pH": np.round(6.4 - 0.5 * (1 - np.exp(-i / 24)), 2),
})

# Cara 1: cetak, salin hasilnya, lalu tempel ke dashboard (Ctrl+V)
print(df.to_csv(index=False))

# Cara 2: simpan jadi file lalu unggah / seret file itu ke dashboard
df.to_csv("data_fermentasi.csv", index=False)
from google.colab import files
files.download("data_fermentasi.csv")
